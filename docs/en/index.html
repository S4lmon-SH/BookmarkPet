Before you start

How do I install it?
  1. Download and unzip the archive.
  2. Move BookmarkPet.app into your Applications folder and open it.
  3. Find the bookmark pet in your menu bar and click it.

This preview has no Developer ID signature or Apple notarization. macOS may block it. If you trust the download, try opening it once, then check System Settings → Privacy & Security → Open Anyway. Managed Macs may not allow this.

Apple’s first-launch instructions·Build from source

Where is my note saved?

In a plain text file on your Mac. No account or cloud transfer. The file is not encrypted by BookmarkPet and remains after you delete the app.

~/Library/Application Support/BookmarkPet/memo.txt

Use the ☰ menu to clear the note or undo the latest clear. Clear undo is available until your next edit or app exit.

Can it launch at login?

Keep the app in your Applications folder, then turn on 로그인 시 실행 (Launch at login) in the ☰ menu. The menu explains when system approval is needed.

Actual reboot/login, Intel Mac, and macOS 13 execution have not yet been verified.
