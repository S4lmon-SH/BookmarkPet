사용 전에

설치는 어떻게 하나요?
  1. ZIP 파일을 내려받아 압축을 풀어요.
  2. BookmarkPet.app을 응용 프로그램 폴더로 옮기고 실행해요.
  3. 메뉴바에서 책갈피 펫을 찾아 눌러요.

현재는 Apple 공증과 Developer ID 서명이 없는 개발 버전이에요. macOS가 차단하면 다운로드를 신뢰하는 경우에 한해 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기를 확인해주세요. 관리되는 Mac에서는 허용되지 않을 수 있어요.

Apple의 첫 실행 안내·직접 빌드하기

메모는 어디에 저장되나요?

내 Mac에 일반 텍스트 파일로 저장해요. 계정이나 클라우드 전송은 없어요. 파일 자체는 암호화하지 않으며 앱을 삭제해도 남아 있어요.

~/Library/Application Support/BookmarkPet/memo.txt

☰ 메뉴에서 비우기와 되돌리기를 할 수 있어요. 되돌리기는 다음 입력이나 앱 종료 전까지 가능해요.

로그인할 때도 켤 수 있나요?

앱을 응용 프로그램 폴더에 둔 뒤 ☰ → 로그인 시 실행을 켜주세요. 시스템 승인이 필요하면 메뉴에 안내가 나타나요.

실제 재로그인·재부팅, Intel Mac·macOS 13에서의 실행은 아직 직접 검증하지 않았어요.

검증 결과

이 홈페이지에서 입력한 내용은요?

체험 메모는 현재 페이지의 메모리에만 있어요. 서버로 보내거나 브라우저에 저장하지 않아요. 새로고침·언어 전환 시 초기화돼요. 별도의 분석·광고 도구도 사용하지 않아요.

호스팅 서비스인 GitHub Pages는 보안 목적으로 방문 IP를 기록할 수 있어요. 자세히
